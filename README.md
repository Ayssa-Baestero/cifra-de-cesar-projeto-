# Projeto da Cifra de Cesar 
Projeto desenvolvido em linguagem C com o objetivo de demonstrar o funcionamento da Cifra de Cesar.

# Sobre o projeto 
Cifra de Cesar é um método de criptografia que substitui a letra de uma mensagem por outra letra deslocada uma determinada quantidade de posições no alfabeto.

# Funcionalidade 
- Criptografar mensagens.
- Descriptografar mensagens.
- Escolher a quantidade de posições que será feito o deslocamento.

# Linguagem utilizada 
Linguagem C.

# Objetivo
Este projeto foi desenvolvido como atividade acadêmica para praticar conceitos de programação, lógica e manipulação de caracteres em C.
